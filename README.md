# 도난국가유산 검색기

국가유산청이 공개한 도난 국가유산 정보(2025년 7월말 기준 인쇄 책자 511건 + 누리집 갱신분 1건
+ 회수완료 1건 = **513건**)를 내장한 1차 대조 도구입니다. 기관·지자체의 취득(구입·기증)
심사 목록이나 반출 감정 물품을 도난 기록과 대조해 검토 후보를 제시합니다.

## 사용

- 브라우저에서 바로 사용: **https://pudgala-appraiser.github.io/stolen-heritage-screener**
- 처음이신 분은 **[사용 안내](https://pudgala-appraiser.github.io/stolen-heritage-screener/manual.html)** 를 먼저 보세요 — 예시 검색어와 결과 읽는 법을 한 쪽으로 정리했습니다.
- 또는 `index.html`을 내려받아 더블클릭으로 실행합니다. 대조 기능은 인터넷 없이도 동작합니다.
  (사진 대조와 환지본처 화면은 저장소의 `images/` 폴더가 함께 있어야 사진이 보입니다.)

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| **환지본처**(還至本處) | 접속·새로고침마다 도난유산 한 점을 보여줍니다. 눈에 익히기 위한 화면입니다. |
| **목록 대조** | 취득·반출 목록을 통째로 넣어 한 번에 대조합니다. 엑셀 파일 업로드, 한글·워드·엑셀 표 붙여넣기, CSV·텍스트 모두 받습니다. |
| **단건 검색** | 유물 하나를 이름·규격으로 조회합니다. |
| **이미지 대조** | 사진 한 장을 넣어 같은 사진이 도난 기록에 있는지 봅니다. |
| **DB 관리·발행** | 신규 공고 등록, 회수 처리, 갱신분 내보내기, 새 HTML 발행. |
| **DB 열람** | 내장 513건을 필터(유물명·지역·ID)로 훑어봅니다. 지역명·인명 조회는 이 탭이 빠릅니다. |
| **도움말** | 사용법과 한계 고지. |

## 이 도구의 성격 (중요)

- 판정자가 아니라 **1차 검색기**입니다. 특정 유물을 "도난품"이라 단정하지 않으며,
  후보와 근거·유사도를 제시하고 최종 판단은 감정위원이 합니다.
- **'통과'는 공개 도난 기록과의 접점 부재**를 뜻할 뿐, 도난품이 아님의 증명이 아닙니다.
  미신고 도난품, DB 기준일 이후 신규 공고, 공개 기록에 사진·규격이 남지 않은 건은 범위 밖입니다.
- 화면에 올리는 질의 자료(목록·사진)는 **브라우저 밖으로 전송되지 않습니다**.

## 대조 방식과 한계

세 채널을 함께 씁니다. 질의에 있는 채널을 모두 동원해 맞춥니다.

1. **텍스트·규격** — 유물명·재질·규격 같은 정형 정보. 513건 전부를 덮습니다.
   전래 고유명사(사찰명·소장처)는 유통 과정에서 지워지기 쉬우므로, 유물에 내재해
   지우기 어려운 정보(각자·명문·간기·규격·희소 유형명)를 신호로 삼습니다.
2. **전문 안전망** — 위 매칭을 통과해도, 질의의 희소 어휘를 원문 전체에서 다시 훑어
   접점이 있으면 맥락 발췌와 함께 표시합니다.
3. **사진 지문** — 지각 해시로 **같은 사진의 재사용**을 잡습니다(현재 816건 보유).
   **새로 촬영된 사진은 원리상 잡히지 않습니다.** 또 도난 목록에는 사진이 없는 건이
   섞여 있어, 그 구간은 사진으로는 대조되지 않고 텍스트·규격에 의존합니다.

소장번호·뒷면 표기·정확한 실측치·보수흔처럼 결정적인 단서는 앞면 사진에 잡히지 않는
경우가 많습니다. 이미지 대조의 정확도에는 천장이 있다는 점을 전제로 쓰십시오.

## 상태 표시

- **회수·잔여 표시** — 부분 회수 건의 사진에는 그 사진 속 유물이 이미 회수됐는지,
  아직 미회수인지를 표시합니다. 회수된 유물을 도난품으로 오인하지 않기 위한 것입니다.
- **유실 참고** — 도난이 아닌 소재불명(유실) 공고 건은 별도 계통으로 표시되며,
  기본 대조에는 섞이지 않습니다.
- **회수 완료** — 전량 회수가 확인된 기록은 경보 대상이 아니며 이력 참고용으로만 표시됩니다.

## 데이터

  게시판(공개 행정정보).
- 모집단: 누리집 게시판은 도난과 유실이 함께 실리지만, **이 도구는 도난 건만** 대조합니다.
- 회수 상태를 반영합니다 — 잔여 수량이 0으로 확인된 건은 경보 대상에서 제외됩니다.
- 후보 카드의 '게시글' 링크는 **전건이 누리집 상세 페이지로 바로 연결**됩니다.

## 갱신

**일상 갱신**(새 공고가 떴을 때)

1. **DB 관리·발행** 탭에서 등록(도난/유실 구분)
2. **갱신 검색기 발행**으로 새 HTML 내려받기
3. 그 파일을 `index.html`로 이름 바꿔 이 저장소에 교체 커밋 — 접속 주소는 그대로입니다.

**사진 추가**

1. `images/{정본ID}.jpg` 규칙으로 저장소에 올립니다(같은 유물의 추가 사진은 `_2`, `_3`…).
2. 새로 올린 파일만 담은 폴더로 지문을 증분 구축한 뒤 발행합니다.
3. 원본을 리사이즈·재압축하지 마십시오. 지문 값이 달라집니다.

**주기 정비**(공고 원문 대조·정본 병합·회귀 검증)는 별도 작업으로 진행합니다.

## 검증

엔진이나 내장 DB를 손댄 발행본은 배포 전 두 가지를 통과해야 합니다.

- **통제 시험 4건** — 페이지를 열면 자동 실행되고 헤더 배지에 결과가 표시됩니다.
- **회귀 테스트 100건** — 가상 취득목록에 대한 기대값(경보 8 · 전문히트 5 · 통과 87) 일치.
