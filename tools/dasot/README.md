# tools/dasot — 「다섯 벌」 화면 적용 도구 (v3.7)

검색기 화면을 「다섯 벌」 디자인으로 바꾸는 데 쓴 도구입니다. 검색기 실행에는 필요 없습니다.
내부 정본처럼 같은 변경을 다른 파일에 입혀야 할 때 씁니다.

| 파일 | 하는 일 |
|---|---|
| `style.css` | 검색기 화면 스타일의 정본. 색·글자 규칙은 파일 머리의 주석에 있습니다. |
| `apply_dasot.py` | `style.css`와 머리·환지본처 마크업, 벌 전환 스크립트를 검색기 HTML에 입힙니다. |
| `manual.css`, `apply_dasot_manual.py` | 사용 안내(manual.html)용. |
| `make_fonts.py` | 제목용 본명조 300·500을 필요한 글자만 추려 `fonts/`에 만듭니다. |

## 내부 정본에 입히기

```
python apply_dasot.py 정본.html --out 정본_다섯벌.html
```

- 표시 층만 바꿉니다. 매칭 엔진·내장 DB·사진 지문은 건드리지 않습니다.
- 여러 번 돌려도 결과가 같습니다. 바꿀 자리를 찾지 못하면 아무것도 쓰지 않고 멈춥니다.
- 판 표기는 3.6 계열일 때만 3.7로 올립니다(`3.6` → `3.7`, `3.6p` → `3.7p`). 건드리지 않으려면 `--no-bump`.
- 적용한 뒤 헤더 배지의 통제 시험 4건과 회귀 테스트 100건을 확인하십시오.

화면을 고칠 때는 `style.css`를 고친 뒤 다시 돌리면 스타일 블록만 갈아 끼웁니다.

## 글꼴 다시 만들기

유물명에 새 한자가 늘어 기기 명조로 보이는 글자가 생기면 다시 만듭니다.
Noto Serif CJK(Light·Medium)와 fonttools·brotli가 필요하며, 글꼴 경로는 `make_fonts.py`의 `SRC`에 있습니다.

```
python make_fonts.py ../../index.html ../../manual.html ../../fonts
```
